- 这个小小的游戏项目来自Code Monkey老师，早就听同学说他的教程很好，如今尝试一次，真的十分认同。

- 仅仅是一个简单的井字游戏，却很好地介绍了多人游戏的使用方法，包括了主机服务器和客户之间什么是互通的什么不是，并且给出了解决办法。清晰、快捷，代码也很干净整洁。UP对于C#事件的使用让我这个基本不用的菜鸟受益良多。

- 先是介绍多人游戏的组件使用，然后快速搭建游戏场景，并实现游戏交互；紧接着就是UI的实现让游戏效果更直观；后续就是一步一步根据现有不足来完成修改。Code Monkey老师对于游戏的解耦十分的彻底，这一点真是令人叹为观止。让我遗憾的是，在大厅匹配的部分由于我此前并未看过他的相关课程，并且相关组件合并后我尝试使用它但是爆出了很多的错误，暂时就没有实现，更好的特效也没有使用。

- 总而言之，这是一个很短但是干货满满的教程，收获很大，值得慢慢体会。
