# **生存射击**

**[该项目来自WITS Gaming](https://www.youtube.com/watch?v=tSkKIqvDTEM)**

- 这个项目是我结束上一个实习之后学习的，由于上一个实习并不是游戏开发（虽然也有使用Unity），因此我又尝试了这一个教程，以便保持手感并学习新内容。

- 不知道是实习使我对Unity的使用更加得心应手了还是这个教程质量不高，至少在跟进时并未感受到太大的阻力。游戏如其名，该游戏属于第三人称的射击游戏，在其中设置了三种僵尸，两种敌人判定方法：一种是敌人在特定地点巡逻，另一种则是玩家进入特定范围后向玩家追逐。和上一个游戏相比看着更为宏大，并且增加了武器的拾取，弹药与生命值的回复以及载具的使用等。任务系统较为简陋，并不是我平时刷的那些光想想就十分消耗时间精力的那种，但是也并不轻而易举，部分任务需要联动略微增加了难度。

- 我不建议学习UP主的该项目，首先是UP声音从始至终的小（虽然我用的字幕，但是很影响观感）；其次，对于涉及的代码，UP没有讲解（至少在我看来讲的不够）。

- 比较有意思的是NavMesh的使用，上一个游戏中我使用的是外部导入的A*资源文件，NavMesh整个大组件提供了非常好的AI寻路。据我浅薄的认知，NavMesh在使用时先是将三维的场景体素化，再根据设计的高度等参数去除掉无法到达的体素点，然后将这些点构烘焙成供算法寻路的网格；下一个阶段由A *算法计算出适合的路径，接着使用漏斗算法将路径变得更为平滑，同时在AI执行的时候还会有障碍物的躲避。用我的南通室友的话来说，离散化、重新连续化、三角剖分、A *（极简）大致是这些，并且在使用的原理上UE和Unity的NavMesh是一样的（我不想用AI优化这些话了Doge）\

[如果各位感兴趣的话，可以去看看](https://zhuanlan.zhihu.com/p/592339133)

- 另外一些之前没见过的比如实现第三人称和第一人称视角切换的组件Cinemachine Camera啥的也挺有意思，开始界面还实现了人物的选择，游玩更加的多样化。但是这个教程的攻击很简陋，玩家和敌人的拳击范围设计成了一个球形区域，也即是能够背对敌人造成伤害，这十分反常识，还有就是载具的移动我感觉不是很丝滑。

- 最崩溃的事是，不知道是我最开始的渲染管线好像没有选择好还是6000.4.2f1版本的编辑器有问题，最开始的地图和人物渲染后十分诡异，尤其是河流的效果，人物则是真的很像僵尸，恐怖如斯（人类没救了）。在和AI齐心协力下地图也是有模有样了，但是人物依旧和鬼一样，因为不影响制作我就将就做了下去，完成制作后感觉人物太丑了也就没有录制视频，今天雄心勃勃我想和AI双排搞定人物渲染，最终的结果是更糟了，渲染小白没有使人物正常，场景也更坏了，游戏逻辑也因为更换了模型渲染而丢失了最初设计好的磨样，不过也算是一种经历，最起码所有的东西还在，只是没有整理。我觉得当时应该只需修改人物模型就行了，大场景并没有问题，AI误我！
