- 这是我真正意义上的第一个Unity项目，Brackeys博主的讲解通俗易懂，同时十分详细，对初入Unity世界的我有极大的帮助。即使是十多年前的项目，却依旧能打，瑞斯拜。

- 该教程，实现了一个麻雀般的2D游戏，基础却全面，包含了玩家移动、跳跃、生命、金钱、射击、UI、动画、A*寻敌等等功能。最为关键的是，Brackeys在讲解时把握得十分精准，既能够让你当时就理解他这样做的效果，同时还能让人在深究下去时依然有所收获。

- 学习过程中最让人痛苦的是，当时我所用的Unity版本是6000.3.8f1，与UP主所用的版本相去甚远，所以在一些方法实现时会出现错误。尤其是，当我在学习实现射击子弹的效果时，出现了我根据教程上的流程完全实现不了的问题，这困扰了我很久。好在我最终实现了，效果差强人意。

- 现在回看这个小项目，它确实有许多的bug，比如玩家会卡在平台下方（碰撞做的不好）；敌人有时候会找不到玩家（暂停时机不对）；波次倒计时问题（动画播放有问题）......但是作为第一步，无疑是成功且稳定的，完成这个教程时的喜悦或许淡忘，不过相信会在下一个项目重逢。
