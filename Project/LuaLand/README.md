- 我觉得这个教程真的非常的棒，最开始从游戏的移动、拾取、胜利开始实现最基础的玩法；接着根据现有不足一步一步地补充完善。整个过程水到渠成，干净利落一点不拖泥带水。

- 越来越多的学习让我逐渐意识到解耦一个游戏十分重要，这能让人逻辑清晰思路明确。CodeMonkey老师在教程中在几乎每一个主游戏对象都添加了代码文件，哪怕这个对象并没有实际需要实现的逻辑，但是我觉得这很好，一方面能方便可能的扩充；另一方面，根据代码组件去判断游戏对象要优于根据游戏对象名字来分辨它们。我之前没有这样做过，但是现在认为这是一个很好的习惯。

- 这次教程，我学到了：新InputSystem的具体使用，不像过去那样一知半解；游戏中如何修改音量（在点击按钮时出发事件）；初步了解到了Unity URP的后处理Volume组件，让游戏画面更加好看；为某些时候为避免使用对象名字转而使用enum枚举来实现，如加载场景；以及一个对我而言很新奇的加载游戏关卡的方法（之前没有碰到过），将游戏场景作为预制件，这样切换的时候不需要频繁切换场景...

- 另外我发现这样井井有条，注释也写的很轻松简洁，唯一可惜的是，游戏的音效在我看来不是很完美，听着总感觉怪怪的容易串戏...不过这是一个很愉快的学习过程！
